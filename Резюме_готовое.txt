Обязанности и достижения:
• Разработал Django-админку каталога для книжного интернет-магазина:
  кастомная Django Admin (модели товаров, категорий, шаблонов Ozon),
  собственные админ-действия и шаблоны.
• Автоматизировал наполнение каталога: скрипты импорта из JSON-файлов

  и автосозданием категорий — вместо ручного ввода тысяч карточек.
• Реализовал экспорт товаров в Excel-шаблоны Ozon (openpyxl): маппинг
  25+ полей с форматированием, готовый к загрузке на маркетплейс файл.
• Написал набор веб-скрейперов книжных каталогов (ast.ru, libex.ru,
  eksmo.ru, litres.ru) — асинхронных (aiohttp/asyncio) и многопоточных
  (threading, ThreadPoolExecutor); скорость сбора ~30–50 карточек/сек.
• Обеспечил устойчивость сбора данных: ретраи с экспоненциальной
  задержкой, ротация User-Agent, обработка rate-limit (HTTP 429/503),
  чекпоинты и режим докачки (--resume) при сборе десятков тысяч карточек.
• Разработал fullstack интернет-магазин на Django (каталог, корзина,
  заказы, отзывы, блог) и учебный AI-проект по дообучению LLM (TinyLlama,
  PEFT/LoRA) с семантическим поиском (sentence-transformers, FAISS).

Стек: Python, Django, PostgreSQL, openpyxl, aiohttp/asyncio, requests,
BeautifulSoup/lxml, Git.

1. Ready — Django-админка каталога для книжного интернет-магазина
   https://github.com/fitnesssensei/ready
   • Backend на Django 5.1 + PostgreSQL (psycopg2), деплой-готовая структура.
   • Кастомная Django Admin: модели товара (Book), категорий (Category) и
     шаблонов Ozon; собственные админ-действия и шаблоны.
   • Скрипты импорта каталогов издательств (Эксмо, АСТ) из JSON-файлов:
     батчевая вставка по 500 записей, дедупликация по ISBN,
     парсинг года/страниц/размеров/веса, автосоздание категорий.
   • Экспорт товаров в Excel-шаблоны Ozon (openpyxl): маппинг 25+ полей,
     форматирование, автоширина колонок.
   • Django management-команды для обработки и нормализации данных.
   • Подготовлен клиент Ozon Seller API (готов к активации).
   Стек: Python, Django, PostgreSQL, openpyxl, python-decouple, JSON.

2. Скрипты обработки и очистки JSON-каталогов (250+ файлов издательств)
   • Парсинг, нормализация и слияние больших JSON-данных (merge_json.py,
     extract_dims.py), приведение размеров/веса к единому формату.
   Стек: Python, регулярные выражения, работа с файловой системой.

3. Асинхронный веб-скрейпер каталога книг (ast.ru)
   https://github.com/fitnesssensei/AST
   • Асинхронная загрузка и парсинг карточек товаров на aiohttp + asyncio
     с настраиваемой конкурентностью (до 50 одновременных запросов).
   • Устойчивость к сбоям: ретраи с экспоненциальной задержкой и джиттером,
     ротация User-Agent, корректная обработка rate-limit (HTTP 429/503).
   • Парсинг HTML через BeautifulSoup (lxml): извлечение 20+ полей из
     JSON-LD (Schema.org), мета-тегов и блока характеристик с мержем по
     приоритету источников.
   • Кэш прогресса — возобновление сборки после прерывания (Ctrl+C),
     сохранение результата в JSONL, отдельный лог ошибок.
   • CLI с argparse; производительность ~30–50 книг/сек (Apple M4 Pro).
   Стек: Python, asyncio, aiohttp, BeautifulSoup, lxml, JSONL.

4. Многопоточные парсеры каталогов издательств (ast.ru, Libex.ru)
   https://github.com/fitnesssensei/libex
   • Сбор ссылок и детальных данных о книгах с нескольких сайтов:
     многопоточный обход каталога (threading, queue) и детальных страниц
     (ThreadPoolExecutor).
   • Работа с cookies и прокси (в т.ч. SOCKS), регулярные выражения для
     извлечения данных из HTML, поддержка кодировки cp1251.
   • Чекпоинты и режим докачки (--resume): пропуск уже обработанных URL
     при обрыве, что важно при сборе десятков тысяч карточек.
   • Гибкий CLI: диапазоны страниц, лимиты, число потоков, таймауты.
   Стек: Python, requests, urllib, threading, регулярные выражения.

5. Многопоточные парсеры каталогов книг (eksmo.ru, litres.ru)
   https://github.com/fitnesssensei/exmo
   • Двухэтапный сбор данных: отдельный парсер ссылок на карточки
     (eksmo_links_parser) с многопоточным обходом каталога (threading,
     queue) и воркеры детальных страниц (ThreadPoolExecutor).
   • Модульная архитектура «воркеров»: EksmoBookDetailWorker и
     LitresBookDetailWorker с единым интерфейсом — переиспользование кода
     под разные сайты с разной разметкой (микроразметка eksmo.ru против
     JSON-LD Schema.org/Book на litres.ru).
   • Извлечение данных через BeautifulSoup и регулярные выражения,
     ротация нескольких наборов User-Agent, случайные задержки и ретраи
     с обработкой сетевых ошибок.
   • Потокобезопасность (threading.Lock), промежуточное сохранение
     результатов в JSON по счётчику и по фоновому таймеру, накопление
     ссылок в txt для устойчивости к прерываниям.
   • Гибкий CLI (argparse): диапазоны страниц/записей (--start/--end),
     число потоков, входные/выходные файлы.
   Стек: Python, requests, BeautifulSoup, threading, ThreadPoolExecutor,
   queue, регулярные выражения, JSON.

6. yabloni — интернет-магазин на Django (fullstack)
   https://github.com/fitnesssensei/yabloni
   • Многоприложенческая архитектура Django 6: каталог товаров (catalog),
     корзина (cart), заказы (orders), отзывы (reviews), блог (blog),
     FAQ и общие компоненты (core).
   • Backend на Django + PostgreSQL (psycopg2), формы на django-crispy-forms
     с Bootstrap 5, загрузка и обработка изображений (Pillow,
     django-multiupload), rich-text через django-ckeditor.
   • Раздача статики через whitenoise, конфигурация через переменные
     окружения (python-dotenv).
   • Серверный рендеринг шаблонов (Django Templates), вёрстка HTML/CSS/JS.
   Стек: Python, Django, PostgreSQL, crispy-forms/Bootstrap 5, Pillow,
   whitenoise, HTML, CSS, JavaScript.

7. myDeepSeek (MyAI) — дообучение LLM и семантический поиск
   https://github.com/fitnesssensei/myDeepSeek
   • Fine-tuning языковой модели TinyLlama на собственном датасете с
     использованием PEFT/LoRA и Hugging Face Transformers (PyTorch).
   • Пайплайн обучения (train.py) с train/val-разбиением и подготовкой
     данных, скрипт проверки модели (test_model.py) и CLI-чат с моделью
     (chat.py).
   • Семантический поиск / RAG: векторизация текстов через
     sentence-transformers и поиск по индексу FAISS (vector_search.py).
   Стек: Python, PyTorch, Hugging Face Transformers, PEFT/LoRA,
   sentence-transformers, FAISS, NumPy, scikit-learn.
